# PrimeStack Tools

Standalone frontend project for a premium digital-tools storefront.

## Scope

- Independent codebase — does not reuse the TopRatedSEOTools repository.
- Frontend only.
- Inspired by the information architecture of GroupSEOToolz.
- 132 tools across 6 categories.
- Searchable and filterable catalogue.
- Responsive desktop, tablet and mobile layouts.
- Mature midnight navy, charcoal, warm ivory and restrained gold visual system.

## Pricing rules

Published numeric prices referenced from TopRatedSEOTools are used where the same tool appears in the PrimeStack catalogue:

- StealthWriter — ₦17,000/month
- ChatGPT Plus — ₦8,500/month
- QuillBot — ₦2,500/month
- Grammarly — ₦2,500/month
- Semrush Guru — ₦3,000/month
- CapCut Pro — ₦5,000/month

All remaining catalogue tools use the standard fallback price of ₦5,000/month.

## Files

- `index.html` — landing page
- `browse-tools.html` — complete searchable catalogue
- `styles.css` — responsive design system
- `app.js` — catalogue data, pricing logic, filtering, mobile navigation and frontend tool-detail modal

## Deployment

The project is plain HTML/CSS/JavaScript and requires no build step. It can be connected directly to a static-site host or imported into ChatGPT Sites.
